A 100-word villain monologue for the make.fun bounty "The Tired Dark Lord" — a fantasy villain who is secretly just very tired speaks: forty years of rehearsed speeches, three kingdoms burned before breakfast, and an apocalypse owed to the realm by Thursday. The program writes the monologue to /output/entry.txt (exactly 100 words, 554 characters).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
